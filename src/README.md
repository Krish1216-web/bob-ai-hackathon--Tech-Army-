# 📦 Source Code Directory (`src/`)

This directory contains the complete source code for **ChainGuard AI**:

- **`backend/`**: FastAPI REST API, SQLAlchemy ORM models, 6 Supabase repositories, decision & anomaly engines, and Pytest test suite.
- **`frontend/`**: React 18, Vite, TypeScript, Tailwind CSS, Leaflet maps, and interactive control tower components.
- **`.env.example`**: Template for environment configuration variables.
